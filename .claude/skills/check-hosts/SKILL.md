# 檢查 coalb 兩台主機

全部都是唯讀操作，可以直接執行，不需要先問使用者。

## 步驟

1. 執行（大約 30 秒）：

   ```bash
   bash .claude/skills/check-hosts/run.sh
   ```

   樹莓派在使用者家裡的區網，只有這台電腦在同一個網段時才連得到。連不到時要分清楚是「樹莓派離線」還是「不在同一個區網」：看最後一段「主站 -> 代理站」，那是從公開網路連的，比較準。

2. 整理成表格回報，**標出需要注意的項目**：
   - 有容器不是 `Up`
   - 磁碟超過 80%，或沒有 swap
   - 等待重開機為 YES，或有安全性更新
   - ufw 沒啟用，或 SSH 允許密碼登入
   - 憑證剩不到 30 天，或 certbot timer 沒在跑
   - 資料庫備份是 0 個，或最新一份超過 2 天
   - Celery 在 24 小時內有錯誤
   - 某個網域的 access log「最後一筆」超過 1 天（代表可能離線過）
   - 兩台的程式版本（commit）不一致，或主機上有未提交的變更

3. 只回報，不要修。重開機、套件更新、改設定、重啟容器，都要使用者確認後才能做（見 `CLAUDE.md`）。

## 維護

主機位址或金鑰變了，用環境變數 `COALB_MAIN_HOST`、`COALB_MAIN_KEY`、`COALB_PROXY_HOST` 覆寫，或直接修改 `run.sh`。
